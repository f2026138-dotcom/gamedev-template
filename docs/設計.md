# 設計
プレイヤー,一撃でゲームーオーバー、Spaceキーで球を出す,画面外に移動できない
敵,プレイヤーが出した球に当たったら、一撃でやられる,移動方向(左右)、5~8秒間隔で球を出す,敵は、5体出てくる、0.5秒待って再出現する、画面外に出ない、敵同士が接触したときは、敵同士が跳ね返る
スコア表示、右上に黒色で、数字を出す、タイトル画面に行ったらスコアを0にリセット
球（プレイヤー、敵、共通）,移動方向(一直線),画面外に出たら消える
球（プレイヤー）,発射できる間隔に制限はなし、敵に当たったら消える、プレイヤーの球は画面に1つしか出せない、
タイトル→Enterキー→プレイ中
プレイ中→Escキー→ポーズ
ポーズ→Escキー→プレイ中
プレイ中→敵に当たる→ゲームオーバー
ゲームオーバー→Enterキー→タイトル
プレイヤーの初期x座標=0
プレイヤーの初期y座標=-50
プレイヤーの移動速度=15
敵の移動速度=5
敵の数＝5
敵のy座標＝50
敵のx座標=ランダム
敵を一体倒すごとのスコア=100
敵の球の発射間隔=5~8秒
球（プレイヤー、敵、共通）の移動速度=17
制限時間=60秒
